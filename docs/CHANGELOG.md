# Changelog

All notable changes to FastFileSystem will be documented in this file.

## [0.1.0] - 2026-08-28

### Added
- Unified High-Performance Filesystem Engine integrating FastFileIndex, FastFileSearch, and FastFileWatch.
- Sub-microsecond Prefix Autocomplete Trie and Fuzzy N-Gram search APIs.
- Real-time NTFS USN Journal live-synchronization engine with automated fallback.
- Comprehensive 120-column ANSI interactive hero demo (`Demo.java` & `run-demo.bat`).
- Standardized JMH Benchmark suite (`FastFileSystemJmhBenchmark.java` & `run-benchmark.bat`).
- Full FastJava ecosystem standardization with `FastCore` native loading and GitHub release metadata.
